1 Le marque-page

Cette page ne peut pas appeler Facebook elle-même. C'est donc ton navigateur qui charge l'Ad Library, normalement, et un petit script y ramasse les pubs pour te les mettre dans le presse-papiers.

  1. Fais glisser le bouton violet dans ta barre de favoris (Ctrl/Cmd+Maj+B pour l'afficher).
  2. Ouvre l'Ad Library et cherche une marque.
  3. Clique le favori, puis fais défiler la page : le compteur monte.
  4. Clique Copier dans le badge, reviens ici, colle ci-dessous.

Comment lire le score

Meta ne publie ni le budget, ni le coût par achat, ni le retour sur dépense d'une publicité commerciale. Aucun outil n'y a accès : quand un outil payant affiche un « chiffre d'affaires estimé », c'est une extrapolation. Le score ci-dessous n'utilise que des signaux réellement publiés.

45 pts
Longévité — personne ne paie deux mois pour une créa qui ne convertit pas. C'est le signal le plus fiable.
25 pts
Duplications — le nombre de copies de la même pub diffusées en parallèle. On duplique ce qu'on scale.
15 pts
Toujours en diffusion aujourd'hui.
15 pts
Portée déclarée, que l'Union européenne impose de publier.

Repère pratique : au-delà de 30 jours de diffusion, une créa est presque toujours rentable.
