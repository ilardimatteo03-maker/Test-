Comment ça marche

D'où viennent les données

De l'Ad Library de Meta — le registre public que Meta est légalement tenu de publier. Toute publicité diffusée sur Facebook et Instagram y figure, consultable par n'importe qui, sans compte. ADSPY interroge cette source publique et garde une copie locale, ce que le site de Meta ne fait pas.

Ce que Meta publie… et ce qu'il ne publie pas

Disponible : le visuel, la vidéo, le texte, le titre, le bouton d'action, l'URL de destination, la date de lancement, les plateformes de diffusion et le nombre de copies d'une même créa. Dans l'Union européenne, s'y ajoute la portée déclarée (transparence DSA).

Jamais publié pour une pub commerciale : le budget, le coût par achat, le ROAS. Aucun outil du marché n'y a accès — quand un outil affiche un « chiffre d'affaires estimé », c'est une extrapolation, pas une donnée. ADSPY préfère afficher des signaux vérifiables.

Le score winner

Note sur 100 calculée à partir des signaux réellement publiés :

  • Longévité — 45 points. Le signal le plus fiable : personne ne paie deux mois pour une créa qui ne convertit pas.
  • Duplications — 25 points. Le nombre de copies de la même pub diffusées en parallèle : on duplique ce qu'on scale.
  • Toujours active — 15 points.
  • Portée déclarée — 15 points. Bonus quand l'UE l'impose.

Si la collecte automatique échoue

Meta durcit régulièrement ses défenses contre les appels automatisés. Le mode navigateur contourne le problème sans rien forcer : tu ouvres l'Ad Library normalement dans ton navigateur, et un petit script recopie vers ADSPY les données que la page a déjà chargées. Tu peux aussi importer un fichier HAR exporté depuis les outils de développement.

Bon usage

Les créas récupérées sont la propriété de leurs annonceurs : elles servent à analyser des angles, des accroches et des formats — pas à être republiées telles quelles. ADSPY limite volontairement son rythme de collecte à une requête par seconde.

Mode navigateur

À utiliser quand Meta bloque la collecte automatique. C'est ton navigateur qui charge l'Ad Library normalement ; le script recopie vers ADSPY ce que la page a déjà reçu.

  1. Installe le marque-page. Fais glisser ce bouton dans ta barre de favoris :
    📎 Capturer vers ADSPY
    Si la barre de favoris est masquée : Ctrl+Maj+B (Cmd+Maj+B sur Mac).
  2. Ouvre l'Ad Library et cherche ta marque : facebook.com/ads/library
  3. Clique sur le marque-page. Un badge violet apparaît en bas à droite.
  4. Fais défiler la page. Chaque nouveau lot de pubs part vers ADSPY, le compteur monte.
  5. Reviens ici : les annonces sont dans ta bibliothèque.
